# Hardware Store Management System

A complete web-based management system for hardware stores built with FastAPI and Jinja2 templates.

## Features
- Dashboard with real-time metrics
- Product & Inventory Management
- Category Management
- Supplier Management
- Customer Management
- Point of Sale (POS)
- Sales & Order Tracking
- Purchase Orders
- Low Stock Alerts
- Reports & Analytics
- User Authentication

## Setup
```bash
pip install -r requirements.txt
python main.py
```
Then visit http://localhost:8000
